# OfferPilot · 精准投递工作台

本地运行的 BOSS 直聘求职助手：整理职位、解释匹配原因、管理投递队列，并通过可见浏览器执行沟通和附件简历发送。

![OfferPilot 工作台](docs/workspace.png)

**当前版本为实验性 MVP。** 队列、匹配、本地存储、界面和模拟页面投递流程有自动测试；**尚未使用真实 BOSS 账号验证登录后的页面及附件发送流程**。BOSS 页面版本、登录状态和风控可能导致自动化暂停，不能保证开箱即投。请先以单个职位验证。

## 功能

- **明确的匹配理由**：关键词评分、城市、月薪下限、公司排除。
- **精选职位队列**：手动导入或从浏览器采集完整职位详情，审核后批量入队。
- **两种执行模式**：仅发起沟通；发起沟通并发送指定的 BOSS 附件简历。
- **简历按批次选择**：设置 BOSS 已上传附件的完整名称，可在不同批次切换版本；不生成、修改或伪造简历。
- **结果分开记录**：沟通成功、简历发送成功、待人工核对；点击按钮不等于投递成功。
- **可靠性措施**：规范化链接去重、每日尝试上限、固定间隔、停止队列、中断恢复；结果未知不自动重试。
- **本地管理**：SQLite、活动记录、CSV 导出，浏览器会话保留在本机。

它面向「先筛选，再投递」的工作流；不包含自动复聊、消息轰炸、反检测绕过或验证码代解功能。

## 快速开始

需要 **Node.js 24 或更高版本**。Windows、macOS、Linux 均可运行；浏览器自动化需要桌面环境。

```bash
npm ci
npm run browser:install
npm start
```

在浏览器打开 **http://127.0.0.1:3210**。

如果电脑已安装 Chrome 或 Edge，可在「投递偏好」选择对应浏览器，省略 Chromium 下载。Linux 可能需要先执行 `npx playwright install --with-deps chromium`。

1. 在「投递偏好」填写关键词、城市、薪资、公司排除和每日额度。
2. 点击「连接 BOSS 浏览器」，在新窗口中手动扫码登录。这里使用独立浏览器配置，不读取你的日常浏览器数据。
3. 在该浏览器打开某个职位的**独立详情标签页**，点击工作台的「采集当前职位」。多个详情标签页存在时采集最后打开的一个；采集后核对公司和职位。也可以手动粘贴链接和职位信息。
4. 选中符合条件的职位，加入队列。点击「开始执行」并确认本轮模式。
5. 默认只发起沟通。发送简历前，请在 BOSS 上传附件，在偏好中选择附件模式并填写**完整文件名**。
6. 待核对记录需要在 BOSS 检查后手动标记。程序不会自动重投已经尝试过的职位。请勿通过删除数据库规避去重。

**「已发起沟通」不代表「已发送简历」。** 已有沟通记录的职位会暂停交由人工处理，不会重复发起或擅自补发简历。

## 匹配规则

匹配分 = 职位名称及描述中命中的关键词数量 ÷ 配置的关键词总数 × 100。关键词不区分英文大小写；无关键词时为 100 分。这是透明的文字匹配，不是 AI 语义评估。

公司排除、城市限制和最低薪资属于硬条件。只比较如 `20-35K` / `20-35K·14薪` 的月薪下限；启用薪资门槛时，日薪、时薪和无法辨认的薪资会被排除。没有设置城市时不限制城市。执行前重新核对职位及最新匹配条件。

## BOSS 页面适配与限制

详细说明见 [docs/boss-adapter.md](docs/boss-adapter.md)。默认选择器是实验适配方案，不是已验证的实时页面契约。

- 自动化只访问网页可见 UI，不调用私有接口，不处理验证码。
- 当前采集单位为一个完整职位详情页，不自动遍历搜索结果。
- 附件发送必须能唯一识别当前会话里的职位、公司、指定附件，以及新增的发送回执；无法识别会暂停。
- 新窗口跳转、嵌套 iframe、平台弹窗和页面改版可能需要更新适配器。
- 当前停止会在下一发送步骤前检查；已经发生的点击或发送无法撤回。
- 每日额度按北京时间统计，开始处理即计入一次；错误也计入，平台自身额度可能更低。
- 一次只运行一个服务进程；不支持多用户或多实例共享数据库/浏览器目录。

## 隐私与文件

`data/` 包含数据库、登录会话及异常截图，已被 `.gitignore` 排除。不要公开上传该目录，或包含个人简历、聊天内容的调试材料。

服务只绑定 `127.0.0.1`，校验 Host、Origin 与自定义写请求头。它是单用户本地工具，不应直接暴露到公网。

| 配置 | 默认 | 用途 |
| --- | --- | --- |
| `PORT` | `3210` | 本地服务端口 |
| `OFFERPILOT_DATA_DIR` | `./data` | 本地数据目录 |
| `BOSS_SELECTORS` | `config/boss-selectors.json` | 自定义选择器文件路径 |

PowerShell 示例：`$env:PORT = '3211'`，随后执行 `npm start`。

## 开发与验证

```bash
npm test
npm run browser:install
npm run test:browser
```

基础测试覆盖评分、URL 校验、去重、限额、未知结果暂停、重启恢复、本地 API 保护及 CSV 导出。浏览器测试用**本地拦截的合成招聘页面**覆盖沟通、附件回执、错误会话、验证码和已有沟通；不会登录 BOSS 或发送真实消息。不能把这些测试等同于真实平台验证。

GitHub Actions 模板位于 [docs/ci.example.yml](docs/ci.example.yml)，包含 Windows 与 Linux 两个平台。当前发布凭证没有 `workflow` 权限，因此模板尚未启用；需要时可通过 GitHub 网页将它保存为 `.github/workflows/ci.yml`。

```text
src/domain.js       匹配、输入校验
src/store.js        SQLite 数据与去重记录
src/runner.js       串行队列与停止/限额
src/boss.js         BOSS 浏览器适配器
src/server.js       本地 HTTP API
public/             中文工作台界面
config/             可维护的页面选择器
test/               核心、API 与浏览器测试
```
